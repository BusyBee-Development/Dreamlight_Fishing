Essential mechanics and loot customization for cozy fishing in Minecraft.

Dreamlight Fishing expands standard fishing with ripple tiers, timing mechanics, and customizable loot tables. Key features include:

* **Ripple Tiers & Rarity:** Dynamic Common, Rare, and Epic fishing spots.
* **Fully Customizable Rewards:** Easily change drop rates and loot tables using standard Minecraft Data Packs.
* **Perfect Catch Bonus:** Custom roll modifiers and mechanics for timed catches.
* **Seamless Integration:** Built to work out of the box with vanilla gameplay or modded servers.

Need help configuring setting files, creating custom ripple pools, or setting up data pack overrides?

## Getting Started

1. Make sure you have the required dependencies installed on your client/server.
2. Place the `.jar` file into your `.minecraft/mods` folder.
3. Launch the game to generate default configuration files.

For full JSON examples, complete loot table paths, and custom configuration tutorials, check out our **[Loot Table Documentation](https://busybeedev.net/docs/dreamlight-fishing/loot)**.
